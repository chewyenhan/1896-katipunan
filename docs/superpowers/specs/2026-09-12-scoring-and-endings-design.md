# 《1896：选择与革命》评分与结局设计

## 目标

评分用于鼓励学生理解历史处境、展现革命意志并顾及集体责任，而不是奖励一味选择最激进的行动。认真参与者通常取得 70–85 分；判断成熟且路线连贯者可以超过 90 分；持续逃避或明显判断失当者才低于 60 分。

总分与结局人格分开计算：总分评价表现，六种结局动画描述玩家的行动风格。低分玩家仍播放人格动画，但结算文案提示其潜能尚未成熟，不设置羞辱性的“失败动画”。

## 三维评分

每个选项独立记录三个 0–100 分的维度：

- 历史判断（40%）：是否理解当时局势、因果和策略条件。
- 革命意志（35%）：是否愿意为民族解放承担行动与风险。
- 团队责任（25%）：是否顾及同志、民众与革命力量的长期存续。

单次选择得分：

`历史判断 × 0.40 + 革命意志 × 0.35 + 团队责任 × 0.25`

最终总分是六次选择得分的平均值，四舍五入为整数。不要再读取旧的单一 `score` 字段作为最终成绩。

## 评级与显示

| 总分 | 等级 | 结算称号前缀 |
|---:|---|---|
| 90–100 | S | 卓越的 |
| 80–89 | A | 成熟的 |
| 70–79 | B | 可靠的 |
| 60–69 | C | 成长中的 |
| 0–59 | D | 尚待觉醒的 |

结算页同时显示总分、等级及三个维度的平均分。例如：`92 / 100 · S级 · 卓越的精明政治家`。排行榜仍按综合总分排序，并保存人格称号。

## 六种结局动画

动画不按总分区间分配。每个选项另外增加一个或两个人格倾向点，游戏结束时累计最高的倾向决定动画：

| 场景与选项 | 人格倾向增量 |
|---|---|
| 研究民族主义思想 | 政治敏锐 +2、同情心 +1 |
| 回家帮助父亲 | 同情心 +3、忠诚 +1 |
| 去市场打听消息 | 政治敏锐 +2、冒险 +1 |
| 为黎萨感到愤怒 | 勇气 +2、同情心 +1 |
| 担心受到牵连 | 同情心 +1 |
| 寻找志同道合者 | 领导力 +2、忠诚 +1 |
| 立刻加入卡地普南 | 忠诚 +2、勇气 +1 |
| 先了解更多 | 政治敏锐 +2 |
| 拒绝加入 | 同情心 +1 |
| 撕碎税证 | 勇气 +2、冒险 +2 |
| 犹豫后加入 | 忠诚 +2、勇气 +1 |
| 后退旁观 | 政治敏锐 +1、同情心 +1 |
| 坚守阵地 | 勇气 +2、忠诚 +1 |
| 撤退保存实力 | 领导力 +2、政治敏锐 +2、同情心 +1 |
| 相信和谈 | 同情心 +2、政治敏锐 +1 |
| 暗中保留武装 | 政治敏锐 +3、领导力 +1 |
| 继续战斗 | 冒险 +2、勇气 +2 |

人格与动画保持现有六种映射：勇气→勇敢的战士；忠诚→忠诚的同志；政治敏锐→精明的政治家；冒险→冒险的革命者；同情心→仁慈的理想主义者；领导力→天生的领袖。

人格计分从六项均为 0 开始，不再用 `100 - fear` 等初始状态间接判断。现行算法中风险承受初始即为 70，而忠诚固定为 30、同情心固定为 50，且目前选择不会更新这两段人物关系，因此结局天然偏向“冒险的革命者”；新的人格点制会消除此偏差。

若最高人格并列，比较并列人格最后一次获得点数的时间，最近体现的倾向胜出；仍无法区分时使用固定顺序：领导力、政治敏锐、忠诚、同情心、勇气、冒险。这样同一份选择记录永远产生同一结局。

## 旧存档与异常处理

- 旧存档已有 `scene`、`choice` 和 `text`，结算时可据此重新查表计算三维分数与人格点，无须清除学生存档。
- 优先按场景 ID 与选择文字匹配；文字匹配失败时才回退到选择索引，避免未来条件选项改变索引后算错。
- 缺失或无法识别的选择不计入平均值，同时在控制台记录警告；若六题全部无法识别，则显示“成绩资料不完整”，不提交排行榜。
- 三个维度和总分均限制在 0–100。

## 验收标准

1. 每条完整路线都能稳定计算三个维度、综合分、等级和一种结局人格。
2. 每题选择表中最高加权分组成的路线可取得约 90 分，能够进入 S 级。
3. 一路选择最激进选项不会自动满分，但应落在 A 级附近并偏向勇敢或冒险结局。
4. 保存实力、暗中保留武装等策略选择能在历史判断与团队责任上得到合理奖励。
5. 六种人格均至少有一条可达路线；同一路线重复游玩必须得到同一动画。
6. 旧存档可重新计算，新旧游戏均不会出现 `NaN`、超过 100 分或空白结局。
7. 排行榜提交的新分数与结算页一致。
